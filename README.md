A 2D martial arts fighting game built with HTML5 Canvas and JavaScript.

**Tech Stack:** Vite + vanilla JavaScript + HTML5 Canvas2D — no frameworks, no heavy dependencies.

## Getting Started

```bash
npm install
npm run dev
```

Open `http://localhost:5173` in your browser.
